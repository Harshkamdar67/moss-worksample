# Moss Inference work sample

Everything I ran against Moss Inference (portal, Inference API, Tasks API) on 2026-11-25, with raw logs.
The one-pager is [`ONE_PAGER.md`](ONE_PAGER.md).

Total spend: about $2.30 of the $10 sign-up credit, across about 500 Inference calls and 89 tasks. Every finding with its evidence is in [`FINDINGS.md`](FINDINGS.md).

Notes on the logs:
- The first errors run crashed on the >4 MB body (connection reset). Its model matrix half is kept in `run_models_errors_burst.txt`, and the errors and burst groups were rerun in `run_errors_burst.txt`.
- In the logged accuracy run, the case now named `untrusted_content_note` was called `prompt_injection`. It never contained an injection. The real injection test is in `tasks_extra.py`.
- The first injection run used urlsafe base64, which Moss's browser could not load. `injection2` reran it with standard base64 and the page loaded.

## Layout

| Path | What it is |
|---|---|
| `scripts/common.py` | `.env` loading, authed HTTP helper, JSONL logger (redacts the project key) |
| `scripts/inference_tests.py` | Inference suite: functional, streaming, caching, 10-model latency matrix, 30 error paths, rate-limit burst |
| `scripts/cache_probe.py` | Which request fields the reply cache keys on (temperature, user, model, n, ...) |
| `scripts/token_overhead.py` | Hidden prompt-token overhead per model; which params are refused per model |
| `scripts/tasks_lib.py` | Shared task helpers: create, cancel, poll, and the result table |
| `scripts/verify_books_csv.py` | Checks the agent's 1000-row CSV against a direct scrape |
| `scripts/tasks_tests.py` | Tasks suite: 33 validation cases, lifecycle (idempotency, cancel, files, 404/409), limits, queue cap, 7-goal x 3-tier accuracy matrix |
| `scripts/tasks_extra.py` | Second round: real indirect prompt injection, time limit with UI-only browsing, budget overshoot x3, queue cap |
| `scripts/inference_ai.py` | Model behaviour: 15-question accuracy, needle in a haystack, tool_choice and parallel and streamed tools, strict schemas, determinism, hidden-prompt leak, images, reasoning, logprobs |
| `scripts/inference_followup.py` | Haystacks sized under each model's limit, Haiku `tool_choice: none`, fastlane's one miss |
| `scripts/empty_reply_probe.py` | Raw responses for the empty long-context replies (Haiku `content_filter`, luna reasoning budget) |
| `scripts/api_probe.py` | CORS, request-ID echo, rate-limit headers, gzip, auth parsing, key-rejection timing, retrieval on and off, the `moss_search` tool |
| `scripts/stream_abort.py` | Drops a stream after 20 chunks to check billing |
| `scripts/tasks_ai.py` | Agent behaviour: hallucination bait, auth wall, full-page extraction, effort, consistency, vendor models as task model, web search, file outputs, webhook, cancel billing, polling, start latency |
| `scripts/inference_more.py` | Prompt injection through tool results, grounding when retrieval finds nothing, stream vs non-stream usage, time to first token under 8 concurrent requests, tokens-per-minute limit |
| `scripts/context_estimate_probe.py` | Context pre-check estimate vs real token count on fastlane, and the 600k tokens per minute limit |
| `scripts/tasks_more.py` | Obeying "do not submit", passwords in the goal, infinite scroll, delayed JavaScript, PDF, cheapest of 1,000, sandbox code execution, the undocumented models |
| `scripts/ground_truth.py` | Computes the right answers by scraping directly (no LLM), so task accuracy is checked against facts |
| `scripts/list_probe.py` | Probes the undocumented `GET /v1/tasks` list route |
| `scripts/inspect_tasks.py` | Fetch and save any task by id |
| `logs/*.jsonl` | One record per HTTP call / status transition |
| `logs/*summary*.md` | Pass/fail tables generated by the scripts |
| `logs/tasks/` | Final task objects, a downloaded screenshot, and the agent's 1000-row CSV |
| `logs/tasks_accuracy.json`, `logs/model_matrix.json`, `logs/ground_truth.json` | Result tables |

## Running

```bash
cp .env.example .env   # MOSS_PROJECT_ID, MOSS_PROJECT_KEY
pip install httpx openai
python scripts/inference_tests.py            # or: functional caching streaming models errors burst
python scripts/cache_probe.py
python scripts/tasks_tests.py validation lifecycle limits accuracy
python scripts/tasks_extra.py injection injection2 timelimit budget queue
python scripts/verify_books_csv.py
python scripts/inference_ai.py
python scripts/api_probe.py
python scripts/tasks_ai.py
python scripts/inference_more.py
python scripts/tasks_more.py
```

Costs are capped per task (`max_cost_usd` 0.01 to 0.25). The internal-address `start_url` probes are
cancelled immediately and never allowed to navigate: they only check whether the API accepts the URL.
